# Proton Drive SDK (Swift)

Swift Package Manager library for [Proton Drive](https://proton.me/drive). It provides Swift bindings over the Drive SDK.

Please read first the guidance on using [the Drive SDK](https://github.com/ProtonDriveApps/sdk).

## Requirements

- macOS 13+, iOS 16+, tvOS 15+, or watchOS 8+ (see `Package.swift` / `Package.Public.swift` for platform pins)
- Swift 6 toolchain
